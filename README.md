# Optics Simulations

Interactive optics simulations built with React, TypeScript, and HTML canvas.
Visualise how mirrors, lenses, prisms, and the eye form images.

## Simulations

- Reflection on a plane mirror
- Image from an ideal thin lens
- Real image from a concave spherical mirror
- Virtual image from a convex spherical mirror
- Anamorphic images
- Primary and secondary rainbows
- Dispersion through a prism
- Eye model: myopia, hyperopia, and corrective lenses

## Tech stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Three.js (rainbow simulation)

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
